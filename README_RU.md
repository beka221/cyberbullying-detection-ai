# Система обнаружения и классификации кибербуллинга

## 🎯 Описание

Интеллектуальная система для **раннего выявления и классификации кибербуллинга** в текстовых сообщениях с использованием машинного обучения и обработки естественного языка.

**Для:** Дипломного проекта (3 человека)  
**Технологии:** Python, FastAPI, React, scikit-learn, NLTK  
**Статус:** Готово к использованию 🚀

## 🚀 Быстрый старт

### Требования
- Python 3.10+
- pip или conda
- VS Code (рекомендуется)

### Установка

1. **Клонируйте репо**
```bash
git clone https://github.com/beka221/cyberbullying-detection-ai.git
cd cyberbullying-detection-ai
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

4. **Загрузите данные NLTK**
```bash
python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords')"
```

5. **Запустите сервер**
```bash
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

6. **Откройте в браузере**
```
http://localhost:8000
```

## 💻 Использование

### Веб-интерфейс
1. Перейдите на `http://localhost:8000`
2. Введите текст для анализа
3. Нажмите "Анализировать"
4. Получите результаты классификации

### API
```bash
curl -X POST "http://localhost:8000/api/analyze" \
  -H "Content-Type: application/json" \
  -d '{"text": "Ваш текст здесь"}'
```
